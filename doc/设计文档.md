# 《观澜》—— 中式恐怖 ARG 设计文档

> 项目代号：观澜（GUANLAN）
> 类型：网页端心理恐怖 ARG / 二手笔记本模拟器
> 语言：中文
> 恐怖原则：心理压迫 > 血腥。全案无尸体、无血、无直接自杀画面。最恐怖的画面是一张被刮掉人脸的合影、一片白纸。

---

## A. 完整世界观设定文档

### A.0 一句话梗概
你拿到一台二手笔记本，前主人是高三（7）班女生林见月。她三天前"转学"了——但教务系统里，她的学号显示为：**该生不存在**。

### A.1 三层时间，叠在同一块地上

| 时间层 | 机构 | 关键事件 |
|---|---|---|
| 1923 | 直隶省立第二女子师范学堂（虚构） | 女学生**沈砚秋**因与同校学生相恋被举报"有伤风化"，校方在古井边"自行处置"，对外称"因病退学"。她的名字与面孔从毕业合影上被刮去。 |
| 2027 | **致稳中学**（虚构）新校区 | 校址建在女师旧址上，古井被水泥封进图书馆地基。学校上线 AI 行为分析系统**「观澜」**：1200 路摄像头、步态识别、微表情分析。 |
| 现在（玩家） | 玩家手中的二手笔记本 | 前主人林见月"转学"，系统记录为"该生不存在"。 |

### A.2 不成文的规矩
1923 年事件后，校方留下一条口耳相传的规矩：**每年大考前，须"出一个人"**，否则"井里的先生要收束"。
到 2027 年，老一辈嘴里的"出一个人"，改由算法完成筛选——**算法即乩童**。

### A.3 「观澜」系统与「群体契合度」
- 核心指标：**群体契合度**（满分 100）。
- 评分逻辑：越孤独、越沉默、越与他人产生私密联结的学生，分数越低。课间独处、双人独处、晚寝后说话、与异性单独同行，均扣分。
- 阈值：35 分。**连续三次低于 35 分**者，系统标红，归类为「待疏导对象」，启动一对一谈话。
- 被判定为"异常"的人，会从所有照片、名单、红榜上被**物理性刮除**，留下指甲抠过的白色纸痕。

### A.4 前世今生（核心母题：刮除 / 重复使用）
林见月与沈砚秋**不是转世**关系，而是"同一个人被这所学校重复使用了一百年"。
每一轮被刮掉的人，都是同一块空白。
终局揭示：**玩家自己也在名单上**。你操作这台笔记本的每一步，都被「观澜」记录为新的"待疏导对象"。

### A.5 恐怖美学守则
- 公文腔、教务腔、平静到冷漠。越平静越恐怖。
- 红榜、跑操方阵、量化考核、誓师大会、查寝点名——全部以虚构方式呈现。
- 全案不出现：真实学校全名/简称/校徽/校长/真实师生姓名。学校统一为虚构名「**致稳中学**」。
- 全案不出现：尸体、血迹、直接自杀画面。
- "刮除"视觉语言：白色指甲划痕、被橡皮擦去的名字、照片上一块空白。

## B. 网页站点结构

### B.1 文件树
```
观澜/
├── index.html              # 单文件游戏（含全部 CSS/JS，双击即玩）
├── 设计文档.md             # 本文档
├── assets/                 # （可选）替换用高清素材
│   ├── desktop_bg.jpg      # 桌面壁纸：模糊班级合影+一道白痕
│   ├── class_photo.jpg      # 高三(7)班合影，一人脸被刮
│   ├── red_board.jpg        # 红榜，一行被刮
│   ├── old_photo_1923.jpg   # 1923女师毕业合影，一人脸被刮
│   ├── well_sealed.jpg      # 被水泥封住的井
│   └── blank_page.jpg        # 终局白纸
└── README.txt
```

### B.2 站点 / 路由说明
本作为**单页应用（SPA）**，不依赖后端。所有"页面"是同一台笔记本桌面里的可拖拽窗口。URL hash 用于存档与定位：

| Hash | 用途 |
|---|---|
| `#boot` | 开机画面（默认起始） |
| `#desktop` | 笔记本桌面（主场景） |
| `#portal` | 教务系统登录窗（P1） |
| `#archive` | 林见月隐藏档案页（P2） |
| `#talk` | 疏导谈话记录（P3） |
| `#well` | 「井」文件夹（P4） |
| `#reality` | 现实锚点锁（P5/P6） |
| `#admin` | 观澜后台（P7） |
| `#ending` | 终局白纸（P8） |

进度存于 `localStorage`，可随时关页面重开。

## C. 八关谜题链详细设计

> 总原则：每一关的答案都"看得见、数得出、查得到"，不靠玄学。

### P1 — 登录教务系统
- **线索来源**：
  - 桌面便签：「别点回收站，别删东西。——见月」
  - 备忘录第一条：「教务快捷方式坏了。真入口在 D:\致稳\portal.exe，要学号。学号在合影背面那排小字里。」
  - 相册 `高三(7)班合影.jpg`：二排学生合影，其中一张脸被白色指甲痕刮去；照片底边有一行手写学号。被刮脸正下方的学号 = **20240714**。
- **玩家操作**：双击相册看合影 → 读出 20240714 → 打开 portal 窗口，学号框输入 `20240714`，姓名自动带出"林见月"。
- **答案**：`20240714`
- **反馈**：屏幕雪花一闪，红字：「登录成功。正在加载该生档案……错误：该生不存在。」停顿两秒，档案页**仍然被解锁**——一个本不该存在的隐藏档案。

### P2 — 数清"低于阈值"的次数
- **线索来源**：
  - 隐藏档案页显示林见月近八周「群体契合度」折线：91 / 88 / 84 / 61 / 42 / 31 / 28 / ??（最后一点被刮掉）。
  - 档案里附《致稳中学群体契合度考核细则》：阈值 35 分；**连续三次低于阈值**者，标记为「待疏导对象」。
- **玩家操作**：数折线里低于 35 的点。可见点中 31、28 两个 < 35；被刮掉的最后一点由 P3 谈话记录反推也是 < 35。玩家在控制台输入"连续几次低于 35 会被标记"。
- **答案**：`3`
- **反馈**：绿字：「判定成立。解锁：疏导谈话记录_0908.pdf。」

### P3 — 「井」文件夹密码
- **线索来源**：
  - 疏导谈话记录（公文体）里，林见月提到"一口井"。谈话教师批注：「幻想内容，不予记录。」记录共三条，日期分别为 **2027-09-08**、2027-09-15、2027-09-22。
  - 备忘录第二条：「那个叫'井'的文件夹，密码是我第一次被叫去谈话那天。格式：月月日日。」
- **玩家操作**：打开被解锁的「井」文件夹，输入 `0908`。
- **答案**：`0908`
- **反馈**：锁开。里面是一份 1923 年的扫描件——《直隶省立第二女子师范学堂 退学证明书》。

### P4 — 一百年的"出一个人"
- **线索来源**：
  - 1923 退学证明书：退学人**沈砚秋**，理由"因病退学"，日期 **1923 年 6 月**。右下角有一行铅笔小字：「照壁之下，井栏之侧。大考前，须出一人。」
  - 备忘录第三条：「观澜后台的密码 = 这条规矩从 1923 年到今年，一共跑了多少年。它不是转世，是同一块空白被反复用。」
- **玩家操作**：在观澜后台登录框输入"规矩延续了多少年"。2027 − 1923 = 104。
- **答案**：`104`
- **反馈**：后台黑屏一瞬，红字滚动：「算法即乩童。正在连接井里的先生……已连接。」

### P5 — 现实锚点一：校训
- **线索来源**：井文件夹里一张半透明的纸条：
  > 「这所学校的根不在 2027。去看它真正的出身——那所把跑操排进课表、被拍成纪录片、被全国中学生当作'高考工厂'原型的中学。把它**官网首页的校训**，按原样输入下面的锁。」
- **玩家操作**：玩家自行打开该真实中学官网（公开页面，仅肉眼阅读，不抓取、不干扰），读出校训，回游戏输入。
- **答案**：该中学官网校训（公开文字，例如"追求卓越"四字；如官网改版，见 G 节顶部常量自行改）。
- **反馈**：「校验通过。根目录解锁。」——游戏全程**不出现该真实学校的名字**，仅以"那所跑操闻名的中学"暗示。

### P6 — 现实锚点二：建校年份
- **线索来源**：解锁根目录后，`观澜_核心算法说明.txt`：
  > 「算法需要一个校准锚。锚 = 上面那所中学**官网上写着的建校年份**。四位数字。输对了，名单才会浮出来。」
- **玩家操作**：回到该官网"学校简介/历史沿革"页，读建校年份，回游戏输入。
- **答案**：四位建校年份（公开数据，如 1951；如官网调整，改 G 节常量）。
- **反馈**：「锚定成功。名单已浮出。」进入 P7。

### P7 — 刮除操作（道德选择 + 关键操作）
- **线索来源**：观澜后台浮出一张红榜名单，共七行。前六行里有若干行已被白色指甲痕刮掉（包括林见月）。第七行正在被系统实时写入——光标跳动，最终拼出**"访客"**二字，并标注：「待刮除对象：访客。执行刮除 →」
- **玩家操作**：界面上有一个大红按钮「执行刮除」。
  - 若玩家点它 → 立刻黑屏重启（坏结局：玩家被刮除，回到开机画面，存档被清）。
  - 正确做法：回到桌面文件树，找到那个名为「**井**」的文件夹，把它**拖进回收站**（或在终端输入 `rm -rf 井`）。
  - 线索：1923 证明书上那句"把井这个字本身，从地图上刮掉"。
- **答案**：删除「井」文件夹。
- **反馈**：所有被刮掉的名字一瞬间全部**复现**在名单上，随即整台笔记本断电。

### P8 — 终局：你在名单上
- **线索来源**：笔记本自行重启。没有登录界面，直接弹出一张**全班合影**——但每一张脸都是空白。
- 屏幕中央一行字：「每一轮被刮掉的人，都是同一块空白。」
- 下方有一个输入框：「请登记你的名字。」
- **玩家操作**：玩家输入任何名字（可以是真名，也可以随便打）。
- **答案**：任意字符串。
- **反馈**：玩家输入的名字，被一道白色指甲痕**当场刮掉**。然后是一整片白纸，只有角落一行小字：
  > ——致稳中学 · 2027 · 该生不存在
  - 底部一个按钮：「再来一遍（你确定吗？）」。点了之后清空存档，回到 P1。

| 尖锐刮擦 | 名字被"刮除"时 | 指甲刮纸，短促刺耳 |
| 低频心跳 | P7 红按钮出现时 | 渐强 |
| 断电声 | P7 删除井后 | 嘎——黑屏 |

> 实现：游戏用 WebAudio Oscillator + NoiseBuffer 实时合成，不依赖任何音频文件，保证双击即跑。
