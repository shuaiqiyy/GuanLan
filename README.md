# 《观澜》

一款纯前端中式恐怖 ARG（替代现实游戏）。表面是一所虚构中学的官网，点进去是一台二手笔记本，再往下是一口井。

- 无框架、无后端、无构建步骤
- 双击 `index.html` 即可玩，也可扔到任意静态托管
- 线上版本：https://zhiwen.xbstu.com.cn

## 运行

```bash
# 本地直接打开
index.html

# 或起一个静态服务器
npx serve .
```

推荐 Chrome / Edge。部分功能（crypto.subtle 哈希）需要 https 或 localhost。

## 文件结构

```
观澜/
├── index.html          # 入口骨架 + 起始页 DOM
├── robots.txt          # 藏教职工线索
├── nginx.conf          # SPA 回退配置参考
├── css/
│   └── style.css       # 全部样式
├── js/
│   ├── config.js       # CONFIG / 文案 / 答案哈希
│   ├── credits.js      # 制作人名单 / 内测信息（唯一维护入口）
│   ├── effects.js      # 刮除动效 / WebAudio / 故障
│   ├── portal.js       # 学校官网各页 + 教职工后台
│   ├── laptop.js       # 二手笔记本内层谜题链
│   └── app.js          # hash 路由 + 井页 + 起始/结束页
└── assets/
    └── audio/          # 音频
```
